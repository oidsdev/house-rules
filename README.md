# House Rules

Answer 10 questions, get a set of safety rules to paste into your AI agent (Muse, Grok Bot, or others).

**Live:** https://agent-house-rules.pages.dev

- 10-question quiz → generates plain-English safety rules
- Settings checklist + test prompts for common agent surfaces
- Short guides (where to paste, per-agent setup)
- Runs 100% on-device. No sign-up, no tracking, no network calls.
- The rules are guidance, not a guarantee — your agent's platform settings are what actually enforce things.

## Native apps

- `ios/` — native SwiftUI iOS app (iOS 17+)
- `android/` — native Kotlin / JetBrains Compose Android app (F-Droid friendly, no Play Services)
