# Bugbot review rules — House Rules (oidsdev/house-rules)

Public directory site for agent house-rules templates.

## Blocking (must flag)

- **No secrets or credentials** in templates, examples, or generated pages.
- **No PII** in committed files.
- **Generated pages must match the generator.** Flag stale generated output.
- **Links must resolve.** Flag dead internal links or references to
  non-existent templates.

## Non-blocking (suggest)

- Copy must be brief and human. No em dashes. No AI-sounding prose.
- Templates should be copy-paste ready with clear placeholder marking.

## Context

- Static site deployed to Cloudflare Pages.
